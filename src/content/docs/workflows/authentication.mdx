## Ringkasan

| | |
| --- | --- |
| Aktor | Semua staf dan nasabah |
| Endpoint masuk | `POST /api/login`, `/api/staff/login`, `/api/customer/auth/login`, `/api/customer/activation` |
| Mekanisme | Token akses pribadi Laravel Sanctum (bearer), disimpan ter-hash di `personal_access_tokens` |
| Autentikasi nasabah | Firebase Authentication (Google OAuth atau Email/Password) di sisi klien, diverifikasi oleh adapter backend |
| Masa berlaku sesi | **Staf:** 480 menit (8 jam) absolut. **Nasabah:** 43.200 menit (30 hari) via `CUSTOMER_SESSION_MINUTES` |
| Cookie / session | Tidak dipakai (API stateless) |

## Alur aktivasi nasabah pertama kali

Nasabah (siswa) tidak menggunakan password akun bank mini. Akun dibuat oleh admin dengan email siswa, lalu siswa mengaktifkan aplikasi sendiri:

## Buka kunci aplikasi (Unlock)

Karena sesi nasabah bertahan hingga 30 hari (`CUSTOMER_SESSION_MINUTES`), aplikasi mobile mengunci layar saat aplikasi diminimalkan atau ditutup.

- Untuk membuka kembali antarmuka, aplikasi meminta 6 digit PIN dan memanggil `POST /api/customer/unlock` `{pin}`.
- Jika salah 3 kali berturut-turut, PIN diblokir selama 15 menit (`pin_locked_until`).
- Buka kunci ini adalah gerbang keamanan di sisi klien untuk melindungi ponsel yang tidak terkunci; token Sanctum tetap aktif untuk panggilan jaringan.

## Memakai token dan logout

Sertakan header berikut pada setiap permintaan:

```http
GET /api/customer/me
Accept: application/json
Authorization: Bearer <token>
```

| Aktor | Profil sendiri | Logout (perangkat ini) | Logout (semua perangkat) |
| --- | --- | --- | --- |
| Staf | `GET /api/staff/me` | `POST /api/staff/logout` | — |
| Nasabah | `GET /api/customer/me` | `POST /api/customer/logout` | `POST /api/customer/logout-all` |

- `POST /api/customer/logout` mencabut token yang dipakai pada perangkat saat ini.
- `POST /api/customer/logout-all` mencabut **seluruh** token Sanctum milik nasabah di semua perangkat yang aktif.

## Saat akses ditolak

| Status | Pesan / `code` | Arti | Tindakan klien |
| --- | --- | --- | --- |
| `401` | `Unauthenticated.` | Token tidak ada, salah, dicabut, atau kedaluwarsa | Hapus token lokal, tampilkan login |
| `401` | `firebase_token_invalid` | Sesi Firebase tidak valid/kedaluwarsa saat login | Masuk ulang ke Firebase |
| `403` | `account_not_linked` | Akun Firebase belum ditautkan ke rekening | Alihkan ke layar aktivasi NIS |
| `403` | `activation_mismatch` | NIS dan email Firebase tidak cocok | Tampilkan pesan kesalahan aktivasi |
| `403` | `Fitur ini khusus untuk staf bank.` | Token nasabah dipakai di endpoint staf | Hapus token, ke login |
| `403` | `Fitur ini khusus untuk nasabah.` | Token staf dipakai di endpoint nasabah | Hapus token, ke login |
| `403` | `Akun staf ini sudah dinonaktifkan.` | Staf diblokir | Hapus token, ke login |
| `403` | `Rekening ini sudah tidak aktif.` | Rekening nasabah ditutup | Hapus token, ke login |
| `422` | `pin_not_set` | Nasabah belum membuat PIN | Arahkan ke layar pembuatan PIN |

Endpoint lengkap: [API Autentikasi](/api/authentication/).
