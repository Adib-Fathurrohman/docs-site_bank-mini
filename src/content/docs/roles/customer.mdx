**Model:** `App\Models\Customer` (tabel `customers`, tanpa nilai `role`). **Klien:**
aplikasi mobile nasabah. **Masuk dengan:** Akun Firebase (Google atau Email/Password), aktivasi rekening via NIS.

Semua endpoint nasabah dibatasi ke rekening milik token. Parameter seperti
`?customer_id=` diabaikan.

## Dapat

| Kemampuan | Endpoint |
| --- | --- |
| Melihat profil sendiri | `GET /api/customer/me` |
| Melihat saldo beserta saldo minimum | `GET /api/customer/balance` |
| Melihat mutasi dengan filter dan detail satu transaksi | `GET /api/customer/transactions`, `/{id}` |
| Mengunduh PDF mutasi sendiri | `GET /api/customer/statement/export` |
| Menampilkan kartu digital (payload QR) untuk dipindai teller | `GET /api/customer/card` |
| Buka kunci aplikasi (unlock) dengan PIN | `POST /api/customer/unlock` |
| Membuat PIN awal (setelah aktivasi / reset) | `POST /api/customer/pin/setup` |
| Mengganti PIN | `POST /api/customer/pin` |
| Melihat, menyetujui (dengan PIN), atau menolak permintaan penarikan untuk rekening sendiri | `/api/customer/withdrawal-authorizations…` |
| Logout perangkat ini | `POST /api/customer/logout` |
| Logout dari semua perangkat | `POST /api/customer/logout-all` |

## Tidak dapat

- **Memulai penarikan atau memindahkan uang** dalam bentuk apa pun. Nasabah hanya
  menyetujui atau menolak penarikan yang dimulai teller.
- Melihat nasabah lain, data staf, jurnal, atau laporan internal.
- Memakai endpoint staf mana pun (`403`).

| Status rekening | Login | Melihat data | Bertransaksi lewat teller |
| --- | :-: | :-: | :-: |
| `active` | ✓ | ✓ | ✓ |
| `suspended` | ✓ | ✓ | — |
| `inactive` (lulus) | — | — | — |

<Aside type="caution" title="Blokir PIN bersama">
Tiga PIN salah berturut-turut, di buka kunci, persetujuan penarikan, atau ganti PIN,
memblokir PIN selama 15 menit di semua tempat. Lupa PIN tidak dapat dipulihkan sendiri;
admin yang me-reset via API.
</Aside>
