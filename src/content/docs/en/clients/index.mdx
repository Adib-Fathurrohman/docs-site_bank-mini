## Production deployment URLs

All services are hosted on VPS infrastructure (`rumput.tech`):

- **Staff Web App:** [https://bank.rumput.tech](https://bank.rumput.tech) — counter teller operations, supervisor reviews, bank administration, and auditing.
- **Customer Web / PWA:** [https://app.rumput.tech](https://app.rumput.tech) — customer portal for balance inquiry, statement history, digital QR cards, and withdrawal authorizations. Android APK releases are distributed via GitHub Releases in `bank-mini-mobile`.
- **Documentation Site:** [https://docs-bank.rumput.tech](https://docs-bank.rumput.tech) — architecture guides, 83 endpoint API reference, database schema, and compliance notes.

<Aside type="tip" title="Backend API URL Recommendation">
Currently, the Laravel backend API is served via reverse proxy on the same origin as the web client: `https://bank.rumput.tech/api` (and `https://app.rumput.tech/api`).

For a dedicated API subdomain:
1. **Primary Recommendation: `https://api-bank.rumput.tech`**
   - Follows the flat single-level subdomain naming pattern aligned with `docs-bank.rumput.tech`.
   - Simplifies Let's Encrypt / Certbot certificate provisioning without multi-level wildcard complexities.
2. **Hierarchical Alternative: `https://api.bank.rumput.tech`**
   - Traditional nested subdomain structure (`api.<app>.<domain>`).
3. **CORS Configuration:** If using a separate API subdomain, ensure Laravel's `.env` configures `SANCTUM_STATEFUL_DOMAINS=bank.rumput.tech,app.rumput.tech` and CORS `allowed_origins` includes `https://bank.rumput.tech` and `https://app.rumput.tech`.
</Aside>
