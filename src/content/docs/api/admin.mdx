## Data referensi

<Endpoint method="GET" path="/api/majors" roles="admin,supervisor,teller" />

Semua jurusan beserta kodenya, tidak dipaginasi, diurutkan berdasarkan nama:

```json
{ "data": [{ "id": 4, "code": "AK", "major_name": "Akuntansi dan Keuangan Lembaga" }, "..."] }
```

Jurusan hanya dapat dibaca; tidak ada endpoint untuk membuat atau mengubahnya.

<Endpoint method="GET" path="/api/settings" roles="admin,supervisor,teller" />

Pengaturan saat ini. Layar teller membutuhkan mode pemindai, saldo minimum, dan mode
verifikasi penarikan.

## Pengaturan

<Endpoint method="PUT|PATCH" path="/api/admin/settings" roles="admin" />

Kirim sebagian atau semua kunci. Responsnya sama dengan `GET /api/settings`.

| Kunci | Tipe | Bawaan | Arti |
| --- | --- | --- | --- |
| `min_balance` | Bilangan bulat 0–1.000.000 | `10000` | Saldo yang harus tersisa setelah penarikan |
| `qr_scanner_mode` | `webcam`, `usb`, `disabled` | `webcam` | Cara layar teller membaca kartu QR (kamera, pemindai USB yang mengetik seperti keyboard, atau ketik manual saja) |
| `withdrawal_verification` | `mobile`, `terminal`, `both` | `mobile` | Persetujuan PIN di aplikasi nasabah, PIN diketik di loket (`POST /teller/withdrawals`), atau keduanya |

```json title="200"
{ "data": { "min_balance": 10000, "qr_scanner_mode": "webcam", "withdrawal_verification": "mobile" } }
```

## Staf

<Endpoint method="GET" path="/api/staff" roles="admin,supervisor" />

<Endpoint method="GET" path="/api/staff/{staff}" roles="admin,supervisor" />

[Staff](#objek-staff) diurutkan berdasarkan nama. `per_page` bawaan 15.

| Query | Keterangan |
| --- | --- |
| `status` | `active` (bawaan), `inactive`, `all` |
| `role` | `admin`, `supervisor`, `teller` |
| `search` | Username atau nama lengkap |

<Aside type="caution" title="L11 · Nilai filter tidak divalidasi">
Nilai `role` dan `status` yang tidak dikenal menghasilkan daftar kosong atau nilai
bawaan, bukan `422`.
</Aside>

<Endpoint method="POST" path="/api/admin/staff" roles="admin" />

Membuat teller atau supervisor.

| Field | Aturan |
| --- | --- |
| `username` | Wajib, huruf/angka/`-`/`_`, maks. 50, unik |
| `full_name` | Wajib, maks. 255 |
| `password` | Wajib, min. 8 |
| `role` | Wajib, `teller` atau `supervisor` (`admin` ditolak) |
| `class` | Opsional, maks. 20 (misalnya `XI AK 2`) |
| `phone` | Opsional, angka, spasi, `+`, `-`, maks. 20 (nomor WhatsApp) |

```json title="201 — contoh dari basis data demo"
{
  "data": {
    "id": 4, "username": "rina", "full_name": "Rina Wulandari", "class": "XI AK 2",
    "phone": "081200000002", "role": "teller", "is_active": true,
    "created_at": "2026-10-27T13:10:36.000000Z", "updated_at": "2026-10-27T13:10:36.000000Z"
  }
}
```

<Endpoint method="PUT|PATCH" path="/api/admin/staff/{staff}" roles="admin" />

Sebagian dari `username`, `full_name`, `password`, `role` (`teller`/`supervisor`),
`class`, `phone`. **403** untuk akun administrator:
`Akun administrator tidak dapat diubah melalui API.`

<Endpoint method="POST" path="/api/admin/staff/{staff}/block" roles="admin" />

<Endpoint method="POST" path="/api/admin/staff/{staff}/unblock" roles="admin" />

Blokir menyimpan akun (riwayatnya harus tetap menunjuk ke akun itu), mengatur
`is_active` menjadi `false`, dan mencabut tokennya. Buka blokir memulihkan akses.
**200** dengan [Staff](#objek-staff) terbaru. **403** untuk administrator.

<Endpoint method="DELETE" path="/api/admin/staff/{staff}" roles="admin" />

Menghapus permanen akun yang belum pernah dipakai. **200**
`{ "message": "Akun staf dihapus." }`. **409** jika ada transaksi, laporan, atau
persetujuan yang merujuknya (`ON DELETE RESTRICT`):

```json
{ "message": "Staf ini memiliki riwayat transaksi, laporan, atau persetujuan sehingga tidak dapat dihapus. Blokir akunnya saja." }
```

<Endpoint method="POST" path="/api/admin/staff/import" roles="admin" />

Membuat banyak teller/supervisor dari spreadsheet. `multipart/form-data` dengan field
`file` (`.xlsx` atau `.csv` dengan pemisah koma atau titik koma, maks. 2 MB, maks. 500
baris). Baris pertama adalah header; header berbahasa Indonesia diterima:

| Data | Header yang diterima |
| --- | --- |
| Username (wajib) | `username` |
| Nama lengkap (wajib) | `full_name`, `nama`, `nama_lengkap` |
| Password (opsional, min. 8) | `password`, `kata_sandi` |
| Peran (opsional, bawaan `teller`) | `role`, `peran` |
| Kelas (opsional) | `class`, `kelas` |
| Telepon (opsional) | `phone`, `no_wa`, `whatsapp`, `no_hp` |

Semua atau tidak sama sekali: jika satu baris tidak valid, tidak ada akun yang dibuat.
Baris tanpa password mendapat password acak 10 karakter, dikembalikan **sekali** di
`generated_password`.

```text title="Contoh file (Excel dengan pengaturan regional Indonesia, pemisah ;)"
Username;Nama;Kelas;No WA;Password
rina;Rina Wulandari;XI AK 1;081200000002;rahasia123
dodi;Dodi Saputra;XI AK 2;081200000003;
```

```json title="201 — contoh dari basis data demo (dipendekkan)"
{
  "data": {
    "created": 2,
    "users": [
      { "id": 4, "username": "rina", "full_name": "Rina Wulandari", "role": "teller", "...": "...", "generated_password": null },
      { "id": 5, "username": "dodi", "full_name": "Dodi Saputra", "role": "teller", "...": "...", "generated_password": "7cCQgOcUs6" }
    ]
  }
}
```

**422:** error dengan kunci `rows.{index}.{field}` (index 0 = baris 2 di spreadsheet),
dan pesannya menyebut baris spreadsheet:

```json
{ "message": "The username (baris 2) has already been taken.", "errors": { "rows.0.username": ["The username (baris 2) has already been taken."] } }
```

## Rekening nasabah

<Endpoint method="GET" path="/api/customers" roles="admin,supervisor" />

<Endpoint method="GET" path="/api/customers/{customer}" roles="admin,supervisor" />

Daftar [Customer](#objek-customer) diurutkan berdasarkan nama (`per_page` bawaan 15).
Rekening yang ditutup disembunyikan dari daftar secara bawaan, tetapi selalu dapat
dibuka berdasarkan id.

| Query | Keterangan |
| --- | --- |
| `search` | Nama, NIS, atau nomor rekening |
| `major_id`, `class`, `group`, `status` | Filter (tidak divalidasi, lihat L11) |
| `activation` | `pending` (belum aktivasi app) atau `activated` (sudah aktivasi) |
| `email` | `missing` (rekening impor tanpa email) atau `present` (memiliki email) |
| `trashed` | `with` menyertakan rekening yang ditutup, `only` hanya menampilkan yang ditutup |

<Endpoint method="POST" path="/api/admin/customers" roles="admin" />

Membuka rekening baru. Nomor rekening dibuat otomatis; rekening mulai `active` dengan saldo
`0`, status aktivasi `pending`, dan tanpa PIN. Field `account_number`, `account_status`, `balance`, dan `pin` diabaikan/ditolak.
PIN dibuat sendiri oleh nasabah di aplikasi Bank Mini setelah aktivasi.

| Field | Aturan |
| --- | --- |
| `nis` | Wajib, maks. 20, unik (termasuk rekening yang ditutup) |
| `full_name` | Wajib, maks. 255 |
| `email` | Wajib, format email valid, maks. 255, unik (disimpan huruf kecil). Digunakan siswa saat aktivasi di aplikasi |
| `class` | Wajib, `X`/`XI`/`XII` |
| `major_id` | Wajib, jurusan yang ada |
| `group` | Wajib, `1`–`4` |

Mengirim field `pin` akan ditolak (**422** `errors.pin: "PIN dibuat oleh nasabah di aplikasi Bank Mini setelah aktivasi."`).

```json title="201 — contoh dari basis data demo"
{
  "data": {
    "id": 4, "account_number": "AK-2026-001", "nis": "20260004", "full_name": "Dewi Anggraini",
    "email": "dewi.anggraini@example.test",
    "activation_status": "pending", "activated_at": null, "pin_set": false,
    "class": "X", "group": "2",
    "major": { "id": 4, "code": "AK", "major_name": "Akuntansi dan Keuangan Lembaga" },
    "account_status": "active", "balance": 0,
    "created_at": "2026-10-27T13:10:36.000000Z", "updated_at": "2026-10-27T13:10:36.000000Z", "deleted_at": null
  }
}
```

<Endpoint method="POST" path="/api/admin/customers/import" roles="admin" />

Membuat banyak rekening nasabah sekaligus dari pembukuan lama beserta saldo dan riwayat transaksi (opsional). Menggunakan `multipart/form-data`:

| Field | Tipe | Aturan |
| --- | --- | --- |
| `file` | file | Wajib, `.xlsx`/`.csv`/`.txt`, maks. 5 MB, maks. 1.000 nasabah. Kolom: `nis`, `nama`/`full_name`, `email` (opsional), `kelas`/`class`, `jurusan`/`major`, `rombel`/`group`, `saldo`/`balance` (opsional), `no_rekening` (opsional) |
| `transactions_file` | file | Opsional, `.xlsx`/`.csv`/`.txt`, maks. 5 MB, maks. 10.000 baris (atau berupa sheet `Transaksi` di `file`). Kolom: `nis`, `tanggal`, `jenis` (`setor`/`tarik`), `nominal`, `keterangan` |

- **Semua atau tidak sama sekali:** Jika ada satu baris yang tidak valid (format NIS/kelas salah, saldo negatif, atau riwayat transaksi menyebabkan saldo di bawah 0), seluruh impor dibatalkan dan mengembalikan **422** dengan rincian per baris spreadsheet.
- **Saldo awal:** Bagian saldo yang tidak dijelaskan oleh riwayat transaksi otomatis dijadikan setoran saldo awal dengan catatan *"Saldo awal dari pembukuan lama"*.
- **Tanpa email:** Rekening yang diimpor tanpa email berstatus `pending` dan dapat bertransaksi di loket teller, namun belum dapat aktivasi aplikasi hingga email diisi via `PATCH /api/admin/customers/{id}`.
- **Transaksi impor:** Terhubung ke batch `customer_imports` (bukan shift teller, `daily_report_id: null`) sehingga tidak mengubah laporan fisik loket dan tidak dapat dikoreksi.

```json title="201 — respons impor berhasil"
{
  "message": "Data nasabah berhasil diimpor.",
  "data": {
    "import_id": 1,
    "customers_created": 25,
    "transactions_created": 150,
    "customers_without_email": 3,
    "customers": [
      { "id": 10, "account_number": "RPL-2026-010", "nis": "20260010", "full_name": "Ahmad Dani", ... }
    ]
  }
}
```

<Endpoint method="PUT|PATCH" path="/api/admin/customers/{customer}" roles="admin" />

Mengubah data nasabah: `nis`, `full_name`, `class`, `major_id`, `group`, `account_status` (`active` atau `suspended`).
Field `email` hanya dapat diubah selama status aktivasi masih `pending` (misal perbaikan salah ketik).
Setelah rekening diaktifkan, email terkunci (**422** `errors.email: "Email tidak dapat diubah setelah rekening diaktifkan."`).
Field `pin` ditolak (**422** `errors.pin: "PIN dibuat oleh nasabah di aplikasi Bank Mini. Gunakan reset PIN jika nasabah lupa PIN."`).
Nomor rekening dan saldo tidak dapat diubah. Rekening yang ditutup menjawab `404`.

<Endpoint method="POST" path="/api/admin/customers/{customer}/pin-reset" roles="admin" />

Mereset PIN nasabah secara langsung oleh administrator:

- Mengosongkan PIN nasabah (`pin_set` menjadi `false`).
- Mengangkat blokir percobaan PIN salah (`pin_failed_attempts = 0`, `pin_locked_until = null`).
- Membatalkan permintaan reset PIN mandiri nasabah yang sedang terbuka (jika ada).
- Nasabah selanjutnya membuat PIN baru di aplikasi mobile setelah login ulang via Firebase (`POST /api/customer/pin/setup`).

**200 OK:**
```json
{
  "message": "PIN direset. Nasabah membuat PIN baru di aplikasi Bank Mini.",
  "data": { "id": 4, "account_number": "AK-2026-001", "pin_set": false, "...": "..." }
}
```

## Permintaan reset PIN nasabah

Endpoint untuk meninjau dan memproses permintaan reset PIN mandiri yang diajukan nasabah melalui aplikasi mobile. Selama permintaan terbuka, transaksi penarikan pada rekening nasabah dijeda untuk melindungi saldo.

<Endpoint method="GET" path="/api/pin-reset-requests" roles="admin,supervisor" />

<Endpoint method="GET" path="/api/pin-reset-requests/{pinResetRequest}" roles="admin,supervisor" />

| Query Parameter | Tipe | Keterangan |

| `customer_id` | integer | Filter berdasarkan ID satu nasabah |

<Endpoint method="POST" path="/api/admin/pin-reset-requests/{pinResetRequest}/approve" roles="admin" />

Menyetujui permohonan reset PIN nasabah (`pending` → `approved`). Admin disarankan memverifikasi identitas fisik siswa terlebih dahulu secara langsung:

| Field | Tipe | Aturan | Keterangan |
| --- | --- | --- | --- |
| `note` | string | Opsional, maks. 255 | Catatan cara verifikasi identitas (misal: "Verifikasi langsung di ruang admin") |

```json
{
  "note": "Siswa datang langsung membawa kartu pelajar."
}
```

- **Notifikasi Push:** Backend mengirim notifikasi push FCM ke ponsel nasabah bahwa permohonan telah disetujui.
- **Masa Tunggu 24 Jam:** Persetujuan admin **tidak memotong** masa tunggu. Nasabah baru dapat memasukkan PIN baru setelah stempel waktu `available_at` tercapai (24 jam sejak pengajuan).
- Mengembalikan **200 OK** dengan objek `PinResetRequest` berstatus `approved`.

<Endpoint method="POST" path="/api/admin/pin-reset-requests/{pinResetRequest}/reject" roles="admin" />

Menolak permohonan reset PIN (`pending` → `rejected`):

| Field | Tipe | Aturan | Keterangan |
| --- | --- | --- | --- |
| `note` | string | Opsional, maks. 255 | Alasan penolakan |

- Mengirim notifikasi push FCM ke ponsel nasabah. Penolakan membuka kembali jeda penarikan tunai pada rekening nasabah. Nasabah dapat mengajukan permohonan baru jika diperlukan.
- Mengembalikan **200 OK** dengan status `rejected`.
- Mengembalikan **409** (`pin_reset_not_usable`) jika status permohonan bukan `pending`.

<Endpoint method="POST" path="/api/admin/customers/{customer}/deactivate" roles="admin" />

Penutupan rekening (lulus/keluar): status rekening menjadi `inactive`, seluruh token Sanctum dicabut, akun Firebase dinonaktifkan di server Firebase, dan dilakukan soft delete. Riwayat transaksi tetap tersimpan.
**200** Customer dengan `deleted_at`. Tidak ada pemeriksaan saldo (lihat L5).

<Endpoint method="GET" path="/api/admin/customers/{customer}/card" roles="admin" />

## Objek

### Objek Staff

`id`, `username`, `full_name`, `class` (nullable), `phone` (nullable), `role`,
`is_active`, `created_at`, `updated_at`. Tidak pernah dikembalikan: `password`,
`remember_token`.

### Objek Customer

| Field | Keterangan |
| --- | --- |
| `id`, `nis`, `full_name`, `class`, `group` | Identitas nasabah |
| `account_number` | Misalnya `RPL-2026-001`, dibuat otomatis |
| `email` | Alamat email terdaftar untuk aktivasi aplikasi |
| `activation_status` | `"pending"` (belum aktivasi) atau `"activated"` (sudah aktivasi) |
| `activated_at` | Waktu aktivasi berhasil (nullable) |
| `pin_set` | Boolean: `true` jika PIN sudah dibuat, `false` jika belum |
| `major` | `{ id, code, major_name }` |
| `account_status` | `active`, `suspended`, `inactive` |
| `balance` | Saldo dalam Rupiah |
| `created_at`, `updated_at`, `deleted_at` | `deleted_at` terisi saat rekening ditutup |

Tidak pernah dikembalikan: `firebase_uid`, `pin` (hash), `pin_failed_attempts`.
