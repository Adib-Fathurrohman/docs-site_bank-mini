Semua endpoint dibatasi ke rekening milik token **nasabah**; `?customer_id=` dan
parameter sejenis diabaikan. Login, profil, dan logout ada di
[Autentikasi](/api/authentication/); persetujuan penarikan ada di
[Otorisasi penarikan](/api/withdrawal-authorizations/#sisi-nasabah).

<Aside type="note" title="Nasabah tidak dapat memindahkan uang">
Tidak ada endpoint nasabah yang membuat transaksi atau permintaan penarikan. Nasabah
hanya dapat menyetujui atau menolak penarikan yang dimulai teller.
</Aside>

## Saldo

<Endpoint method="GET" path="/api/customer/balance" roles="customer" />

```json title="200 — contoh dari basis data demo"
{
  "data": {
    "account_number": "RPL-2026-001", "full_name": "Budi Santoso", "account_status": "active",
    "balance": 595000, "min_balance": 10000, "as_of": "2026-10-27T13:10:40.302817Z"
  }
}
```

## Mutasi

<Endpoint method="GET" path="/api/customer/transactions" roles="customer" />

Mutasi, terbaru dulu, `per_page` bawaan 20. Filter `from`, `to`, `type`. Baris
[StatementLine](#objek-statementline) tidak memuat teller atau jurnal:

```json title="200 — contoh dari basis data demo"
{
  "data": [
    { "id": 5, "type": "withdrawal", "direction": "out", "description": "Tarik tunai", "amount": 30000, "balance_after": 595000, "created_at": "2026-10-27T13:10:37.000000Z" },
    { "id": 4, "type": "deposit", "direction": "in", "description": "Setor tunai", "amount": 125000, "balance_after": 625000, "created_at": "2026-10-27T13:10:36.000000Z" }
  ]
}
```

<Endpoint method="GET" path="/api/customer/transactions/{transaction}" roles="customer" />

Satu baris milik sendiri (**404** untuk milik nasabah lain).

<Endpoint method="GET" path="/api/customer/statement/export" roles="customer" />

PDF mutasi sendiri (`mutasi-RPL-2026-001.pdf`) dengan `?from=&to=`: saldo awal, setiap
baris dengan saldo berjalan, dan total.

## Kartu digital

<Endpoint method="GET" path="/api/customer/card" roles="customer" />

Bentuknya sama dengan kartu di sisi admin, dengan `qr_payload`
(`BANKMINI:{account_number}`) untuk ditampilkan sebagai kode QR di loket. Payload QR
hanya mengidentifikasi nasabah, tidak mengotorisasi apa pun (L17).

## Ganti PIN

<Endpoint method="POST" path="/api/customer/pin" roles="customer" />

| Field | Aturan |
| --- | --- |
| `current_pin` | Wajib, 6 digit |
| `new_pin` | Wajib, 6 digit, berbeda dari `current_pin`, dikonfirmasi |
| `new_pin_confirmation` | Harus sama dengan `new_pin` |

**200** `{ "message": "PIN berhasil diubah." }`. `current_pin` yang salah dihitung ke
blokir yang sama dengan login dan penarikan (**422** dengan `remaining_attempts`).

## Objek StatementLine

`id`, `type`, `direction` (`in`/`out`), `description` (label berbahasa Indonesia),
`amount`, `balance_after`, `created_at`.
