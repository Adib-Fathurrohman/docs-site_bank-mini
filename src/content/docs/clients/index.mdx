## Alamat URL produksi

Setiap layanan diarahkan ke domain pada VPS (`rumput.tech`):

- **Aplikasi Staf:** [https://bank.rumput.tech](https://bank.rumput.tech) — portal operasional loket teller, supervisor review, administrasi bank, dan audit.
- **Aplikasi Nasabah (PWA / Web):** [https://app.rumput.tech](https://app.rumput.tech) — portal digital nasabah untuk cek saldo, mutasi, kartu QR, dan persetujuan penarikan. Rilis Android APK tersedia melalui GitHub Releases repositori `bank-mini-mobile`.
- **Situs Dokumentasi Teknis:** [https://docs-bank.rumput.tech](https://docs-bank.rumput.tech) — buku panduan arsitektur sistem, referensi 83 API endpoint, skema basis data, dan tata kelola perbankan.

<Aside type="tip" title="Rekomendasi URL API Backend">
Saat ini backend Laravel diakses melalui reverse-proxy pada origin yang sama dengan aplikasi web: `https://bank.rumput.tech/api` (dan `https://app.rumput.tech/api`).

Untuk konfigurasi subdomain mandiri (*dedicated API domain*):
1. **Pilihan Utama (Direkomendasikan): `https://api-bank.rumput.tech`**
   - Mengikuti pola penamaan *flat single-level subdomain* yang konsisten dengan `docs-bank.rumput.tech`.
   - Penerbitan sertifikat SSL Let's Encrypt / Certbot sangat mudah tanpa memerlukan sertifikat multi-level atau wildcard khusus.
2. **Alternatif Hierarkis: `https://api.bank.rumput.tech`**
   - Standar industri sub-subdomain (`api.<app>.<domain>`), rapi secara struktur hirarki.
3. **Konfigurasi CORS:** Jika menggunakan subdomain API terpisah, pastikan file konfigurasi `.env` Laravel mengatur `SANCTUM_STATEFUL_DOMAINS=bank.rumput.tech,app.rumput.tech` dan CORS `allowed_origins` mencakup `https://bank.rumput.tech` dan `https://app.rumput.tech`.
</Aside>
